# Community Code of Conduct

Project Sweep welcomes people who want to improve safe, understandable local cleanup tools.

## Expected behavior

- Be respectful, specific, and patient.
- Critique ideas and code without attacking people.
- Respect privacy. Never repost another person's paths, files, credentials, or conversation content.
- Use generated fixtures when reporting cleanup behavior.
- Accept maintainer decisions about project scope and data-safety boundaries.

Harassment, discrimination, threats, doxxing, and deliberately unsafe instructions are not acceptable.

## Enforcement

Maintainers may edit or remove content, close contributions, or restrict participation when needed to protect contributors and users. Report ordinary conduct problems in a concise GitHub issue without reposting harmful or private content. If a report includes a security or privacy vulnerability, use [private vulnerability reporting](https://github.com/Oliverzheng0727/project-sweep/security/advisories/new).
