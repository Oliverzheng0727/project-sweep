## 0.2.3 扫描性能与进度

对正在运行的 0.2.2 扫描线程进行 3 秒只读采样，主要耗时落在两次逐文件遍历 Git 跟踪集合及重复转换 URL 路径。改为每次扫描建立「已跟踪文件及其父目录」集合，查询使用完整路径键，嵌套仓库和包的 Git 结果继续补充索引。索引不跨扫描复用，执行前校验保持不变；同时去掉界面接收同一结果后多余的概览重算。

新增回归覆盖：跟踪文件已从工作区消失时仍保护其父目录、相似前缀目录不误保护、嵌套仓库与不展开的文档包、重新扫描刷新 Git 状态，以及扫描开始即报告进度。缺失文件回归另外发现 `/private/var` 与 `/var` 的路径表示差异；现在先标准化存在的仓库根目录，再拼接 Git 相对路径，避免缺失文件导致父目录漏保护。
