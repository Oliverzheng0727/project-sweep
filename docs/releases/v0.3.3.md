Project Sweep 0.3.3 is the first packaged public release of the native macOS cleanup utility.

### Highlights

- Inspect one AI-assisted project at a time in a clear tree or compact list.
- Keep finished work while selecting known caches, or review removal of the entire project.
- Inspect supported local Codex, Claude Code, and Cursor data with fail-closed format checks.
- Discover and manage Claude Code and Codex skills separately.
- Follow macOS light/dark appearance and the system accent color.

### Requirements

- Apple Silicon Mac
- macOS 14 or later

### Install

Download `ProjectSweep-macOS-arm64.zip`, extract it, and move **Project Sweep.app** to Applications. The app uses an ad hoc local signature and is not notarized; on first launch, Control-click the app and choose **Open** if macOS blocks a normal double-click.

The source archive and SHA-256 checksums are attached for verification. See [CHANGELOG.md](https://github.com/Oliverzheng0727/project-sweep/blob/main/CHANGELOG.md) for version history and [SECURITY.md](https://github.com/Oliverzheng0727/project-sweep/blob/main/SECURITY.md) for private vulnerability reporting.
