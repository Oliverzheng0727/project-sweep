Project Sweep 0.4.0 adds a complete English interface while keeping the existing Simplified Chinese experience.

### Highlights

- Follow the macOS language or choose English or Simplified Chinese in Settings.
- Apply language changes immediately across project cleanup, tool data, skills, cleanup history, settings, safety messages, dates, sizes, and accessibility labels.
- Keep filenames, project names, and AI tool names unchanged when switching languages.
- Replace the repository's compressed screenshots with lossless Retina PNGs in English.
- Verify localization coverage and duplicate keys in CI.
- Bundle every localization resource in the app for reliable standalone startup.

### Requirements

- Apple Silicon Mac
- macOS 14 or later

### Install

Download `ProjectSweep-macOS-arm64.zip`, extract it, and move **Project Sweep.app** to Applications. The app uses an ad hoc local signature and is not notarized; on first launch, Control-click the app and choose **Open** if macOS blocks a normal double-click.

The source archive and SHA-256 checksums are attached for verification. See [CHANGELOG.md](https://github.com/Oliverzheng0727/project-sweep/blob/main/CHANGELOG.md) for version history and [SECURITY.md](https://github.com/Oliverzheng0727/project-sweep/blob/main/SECURITY.md) for private vulnerability reporting.
