Project Sweep 0.5.0 adds multiple project libraries, a more compact native workspace, skill relationship browsing, and operation-level restore.

### Highlights

- Native sidebar and toolbar commands keep search, refresh, and view switching close at hand. Compact project headers and a resizable file inspector leave more room for the tree.
- Save multiple project locations with independent folder access. Your previous library migrates automatically; missing locations remain available for retry or reconnection. Removing a library entry does not delete its files.
- Browse skill source relationships across Claude Code and Codex. The read-only view distinguishes originals, references, AI ownership, and incomplete scan evidence without merging same-name skills or claiming they are enabled.
- Review and restore eligible files from one cleanup operation together. The review lists exact destinations, excludes irreversible sessions, and reports conflicts and partial results without overwriting existing files.

### Validation

126 core tests passed with no failures or skips, including the installed Codex CLI 0.147.0 protocol test in an isolated temporary home. 69 UI state checks and 664 English localization entries passed. Cleanup and restore tests use generated data only. Cursor session deletion remains disabled.

Native GUI checks covered library switching, toolbar search, keyboard opening, file previews, skill relationships, language and appearance switching, and a two-file restore with one deliberate naming conflict. The existing file remained unchanged. The final arm64 app was built, packaged, signature-verified, installed, and launched. The detailed acceptance record documents scope and limitations.

### Install

Requires Apple Silicon and macOS 14 or later. Download `ProjectSweep-macOS-arm64.zip`, extract it, and move **Project Sweep.app** to Applications. This release uses an ad hoc local signature and is not Apple-notarized. The source archive and SHA-256 checksums are attached.
