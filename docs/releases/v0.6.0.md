Project Sweep 0.6.0 improves project inspection with verified cache rules, persistent historical scan totals, and storage filters.

### Highlights

- Recognize default Next.js, Parcel, and Vite cache locations only with bounded local manifest evidence. Show the producer and the impact of regenerating caches. Ambiguous dependency replacements stay manual, and authored files at any depth keep a folder out of quick selection.
- Keep the last complete scan's aggregate sizes and time across restarts. Historical totals are explicitly marked unverified; file inventories and cleanup selections are never restored from this cache. Cleanup still requires a current scan and execution-time checks.
- Explore a compact storage breakdown and combine type and minimum-size filters. Statistics avoid counting parent folders twice; filtered trees retain unselectable ancestors and preserve existing selections.

### Validation

145 core tests passed with no failures or skips, including the installed Codex CLI 0.147.0 protocol test in an isolated temporary home. 82 UI state checks and 694 English localization entries passed. Cleanup and restore tests use generated data only. Cursor session deletion remains disabled.

Native GUI checks used an isolated generated project library and separate preferences. They covered cache evidence, type and size filters, hidden selections, tree/list switching, historical totals after restart, the cleanup review, small windows, and both languages and appearances. A text-layout overflow found during acceptance was fixed and rechecked. The final arm64 archive and installed app passed signature verification. See the detailed acceptance record for scope and limitations.

### Install

Requires Apple Silicon and macOS 14 or later. Download `ProjectSweep-macOS-arm64.zip`, extract it, and move **Project Sweep.app** to Applications. This release uses an ad hoc local signature and is not Apple-notarized. The source archive and SHA-256 checksums are attached.
