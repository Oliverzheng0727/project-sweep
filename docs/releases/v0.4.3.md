Project Sweep 0.4.3 fixes tool-history visibility, preserves project selections during related-record discovery, and improves English consistency.

### Highlights

- A malformed Codex record no longer hides every other session. Readable metadata remains visible; incomplete dependency inventories stay read-only.
- Related Records no longer rescans the project or clears selected project files when discovering tools. Requests made during a file scan continue afterward.
- Completed tool results appear immediately. Manual refresh retries cancelled or incomplete inspections and keeps project-file selections.
- Directory discovery runs in the background and reports inaccessible locations, missing folders, and explicit disconnects. Custom folder connections start scanning immediately.
- Default session titles follow English or Simplified Chinese throughout the interface; user titles remain unchanged.
- Build scripts support Swift 6.4 and avoid sync-folder attributes that can break bundle signing.

### Validation

112 core tests passed, including the installed Codex CLI 0.147.0 protocol test in an isolated temporary home. 55 UI state checks and 597 English localization entries passed. Real local history was inspected read-only; cleanup tests used generated data only. Cursor session deletion remains disabled.

### Install

Requires Apple Silicon and macOS 14 or later. Download `ProjectSweep-macOS-arm64.zip`, extract it, and move **Project Sweep.app** to Applications. This release uses an ad hoc local signature and is not Apple-notarized. The source archive and SHA-256 checksums are attached.
