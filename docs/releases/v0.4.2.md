Project Sweep 0.4.2 removes the manual setup step for standard AI tool data folders.

### Highlights

- Automatically discover and scan existing Codex, Claude Code, and Cursor standard data folders when opening Tool Data or a project's Related Records.
- Limit discovery to `~/.codex`, `~/.claude`, and `~/Library/Application Support/Cursor`; the app does not search the entire home folder or other projects.
- Skip symbolic-link roots and retain all existing read-only, format-validation, and cleanup-confirmation safeguards.
- Keep custom folder selection for each tool and remember an explicit disconnect until the user reconnects it manually.
- Add a Discover and Scan Again action and matching English and Simplified Chinese interface text.

### Requirements

- Apple Silicon Mac
- macOS 14 or later

### Install

Download `ProjectSweep-macOS-arm64.zip`, extract it, and move **Project Sweep.app** to Applications. The app uses an ad hoc local signature and is not notarized; on first launch, Control-click the app and choose **Open** if macOS blocks a normal double-click.

The source archive and SHA-256 checksums are attached for verification.
