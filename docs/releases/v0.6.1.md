Project Sweep 0.6.1 strengthens cleanup boundaries and improves browsing performance and accessibility.

### Highlights

- Keep rules on a parent folder now protect nested projects from whole-project removal. Directly organizing a folder inside an AI tool configuration directory retains system protection.
- Final removal-scan verification checks the original inventory, including opaque version-history folders. Added or modified files require a fresh scan instead of silently becoming part of the removal plan.
- Incomplete sizes propagate to parent folders and appear consistently in file rows, details, and storage totals.
- Space filters reuse the scan's classification index, and project-library filters agree with the availability shown on cards.
- Project-card accessibility values include creation dates, sizes, scan times, historical status, and availability. Available cards expose an Inspect Project action.

### Validation

154 core tests passed with no failures or skips, including the installed Codex CLI 0.147.0 protocol check in an isolated temporary home. 89 UI state checks and 694 English localization entries passed. Language tests now use process-local preferences to avoid interference between simultaneous test runs.

In a release-mode benchmark of the same 30,301 generated records, median filter query time fell from 0.498 seconds to 0.051 seconds. Initial scan-summary/index preparation still took 0.797 seconds, and the cached query plus tree construction took 0.175 seconds. These are local measurements, not general scan-speed guarantees.

Native checks used generated projects and separate preferences. They covered partial directory sizes, disabled whole-project removal for unverifiable content, keyboard and accessibility opening, hidden selections, tree/list switching, cleanup review, historical summaries after restart, English/light and Chinese/dark appearances, and a compact window. No real project, skill, or history was cleaned. Cursor session deletion remains disabled.

The final archive and installed app passed strict signature verification.

### Install

Requires Apple Silicon and macOS 14 or later. Download `ProjectSweep-macOS-arm64.zip`, extract it, and move **Project Sweep.app** to Applications. This release uses an ad hoc local signature and is not Apple-notarized. The source archive and SHA-256 checksums are attached.
