Project Sweep 0.4.1 improves project navigation, first-run tool setup, and bilingual interface consistency.

### Highlights

- Switch the full interface between English and Simplified Chinese immediately, including the sidebar and bottom status area.
- Filter the project library by recent, scanned, cached, or unavailable projects, and pin frequent projects to the top.
- Keep project counts consistent by excluding the synthetic root row while clearly labeling the protected root.
- Detect standard Codex, Claude Code, and Cursor data folders in a guided setup view before separate authorization.
- Give the file tree more room at the minimum supported window size.

### Requirements

- Apple Silicon Mac
- macOS 14 or later

### Install

Download `ProjectSweep-macOS-arm64.zip`, extract it, and move **Project Sweep.app** to Applications. The app uses an ad hoc local signature and is not notarized; on first launch, Control-click the app and choose **Open** if macOS blocks a normal double-click.

The source archive and SHA-256 checksums are attached for verification. See [CHANGELOG.md](https://github.com/Oliverzheng0727/project-sweep/blob/main/CHANGELOG.md) for version history and [SECURITY.md](https://github.com/Oliverzheng0727/project-sweep/blob/main/SECURITY.md) for private vulnerability reporting.
