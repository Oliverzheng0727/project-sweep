# Support

Use [GitHub Issues](https://github.com/Oliverzheng0727/project-sweep/issues/new/choose) for reproducible bugs and focused feature requests. Include the Project Sweep version, macOS version, affected product area, and steps using generated or disposable test data.

Remove personal paths, private project names, conversation text, tokens, and credentials from screenshots and logs. Do not attach real AI tool databases or project archives.

Report security or privacy vulnerabilities through [private vulnerability reporting](https://github.com/Oliverzheng0727/project-sweep/security/advisories/new), not a public issue.
